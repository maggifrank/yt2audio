# yt2audio

Convert YouTube videos to audio files.

## Setup

```sh
cp .env.example .env   # then edit .env with your own values
```

## Secrets

This repository is public. Never commit secrets: `.env`, API keys,
credentials, private keys and cookies files are all ignored by
`.gitignore`. Put real values only in your local `.env`; add new
settings to `.env.example` with placeholder values.
